## 已解决问题

- `run_loc_online` 原先不能直接接受 ROS 2 remap 参数；已通过调整参数解析解决。
- Lightning `map -> base_link` 与底盘 `odom -> base_link` 的双父节点冲突已通过 `/lightning_tf` 隔离和 wrapper 解决。
- Lightning 原始地图约 5 度倾斜的问题已通过外部水平 `map` frame 验证解决方向。
- `map -> lightning_map` static TF 已固化进集成定位 launch。
- 集成定位 launch 已通过同包完整 bag TF 复验。
- Nav2 静态地图不能直接使用 Lightning g2p5 输出的问题已定位：g2p5 工作在倾斜 `lightning_map` 内部坐标。
- `global.pcd` 缺少 free-space visibility 导致 free 区域过少的问题，已通过原始 MID360 bag + Phase 3E TF 的 ray tracing 恢复 observed free。
- 机器人自身轨迹在静态栅格中形成 occupied artifact 的问题，已通过缩小 footprint 的轨迹清理解决。
- PGM unknown 像素被 map_server 阈值误判为 free 的序列化 bug 已修复，并增加写图前语义校验。
